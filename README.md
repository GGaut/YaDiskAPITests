### Тест кейс:

## Получение списка файлов через API

**Предусловие:**

- Создать папку TestFolder
- Создать два файла в папке TestFolder: "data1.txt", "data2.txt"

**Шаги:**

1. Отправить PUT запрос https://cloud-api.yandex.net/v1/disk/resources/files
2. Проверить код ответа.
3. Проверить json в теле ответа.

**Ожидаемый результат:**

- Код ответа на PUT запрос: 200 Ok
- В теле ответа есть поля "name" со значениями "data1.txt", "data2.txt"
- Тело ответа соответсвует схеме

**Постусловие:** удалить созданную папку
